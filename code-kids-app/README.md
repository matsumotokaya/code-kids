# コードキッズ（code-kids-app）

子ども向け（6歳・8歳）のプログラミング学習ブラウザゲーム集。
ログイン → ストアでゲームを「ダウンロード」→ 遊ぶ、という流れで、ゲームを1本ずつ増やしていく。

| ゲーム | 状態 |
|---|---|
| ほしあつめ | 遊べる。カードを並べてキャラクターを動かし、おほしさまを集めるパズル。旧アプリ「おえかきロボとさんすうのあそびば」の「おえかきロボット」をゼロベースで作り直したもの |
| ピッタリジャンプ | 遊べる。けいさんカードを並べてカエルを数直線の上で跳ばし、ゴールの数にぴったり止める。旧アプリの「ピッタリジャンプ」を、ほしあつめと同じ「並べてから実行」の形に作り直したもの |
| みずのみち | 遊べる（300コインで買う）。くだを回したり置いたりして、「ながす！」でじゃぐちの水を花まで届けるパズル。12ステージ |
| まほうのアート | 遊べる。指でなぞった線が選んだ数だけ円の周りに増える万華鏡。旧アプリの「まほうのアート」（円周上の点をかけ算で結ぶ）は意味が伝わらず遊ばれなかったため、数で結果が大きく変わる点だけ残して作り直した |

**本番: https://code-kids-inky.vercel.app/**

## あそびかた

### ログインとストア

1. 最初にパスワードを入れてログインする。パスワード（合言葉）は4人分で、`src/store/session.ts` の `USERS` にある。大文字・小文字は区別しない。本物の認証ではなく「誰の記録を出すか」を決めるだけ
2. ストアでアイコンをタップ →「ダウンロードしますか？」→ 0〜100% のダウンロード演出（約6秒）→「ひらく」で遊べる
3. アイコンを長押しすると「けしますか？」が出て、アプリを消せる。消しても★の記録は残り、入れ直すと続きから遊べる
4. 右上のコインはステージのクリアでたまり、新しいアプリを買うのに使う（下の「コイン」）
5. 右上の名前をタップするとログアウトできる。ダウンロード済みのアプリもゲームの記録も、ログインした人ごとに別々

### コイン

1. ステージをクリアすると、そのステージの一番いい★に応じてコインがもらえる。★1 = 30、★2 = 40、★3 = 50
2. 同じステージをもう一度クリアしても、★が増えたときの差分（★1→★3 なら +20）しか増えない。ステージ1の繰り返しでは稼げない
3. ほしあつめはキャラごとに記録が別なので、別のキャラで同じステージをクリアするともう一度もらえる。まほうのアートはステージが無いのでコインは無い
4. 値段のあるアプリ（`catalog.ts` の `price`）は、ストアで「かう」とコインが減ってダウンロードが始まる。足りないときは「あと ○コイン たりないよ」と出る
5. 買ったアプリは消しても買ったまま。入れ直しは無料
6. 残高は保存していない。毎回「全ゲームの一番いい記録から計算したコイン − 買ったアプリの値段の合計」で出す（`src/store/coins.ts`）。そのためコイン導入前に取った★もそのままコインになっている。値段を表示どおりに保つため、買ったときの値段を記録している

### ほしあつめ

1. タイトルでキャラクター（ロボ / ネコ / ウサギ）を選ぶ。ログインした人ごと・キャラごとに進捗が保存される。左上のボタンでストアに戻る
2. マップでステージを選ぶ（前のステージをクリアすると次が開く）
3. カード（うえ / した / ひだり / みぎ）をタップして並べ、「うごけ！」で実行
4. 「2かい」「3かい」カードは直前のカードに掛かり、そのカード1枚で 2 / 3 マス進む（かけ算・くり返しの導入）
5. いわ・ばんの外にぶつかる、みずに落ちる、ほしが残る、と失敗。カードは消えないので直してもう一度
6. 少ないカード枚数でクリアすると ★3（各ステージの `par` が基準）

### ピッタリジャンプ

1. マップでステージを選ぶ。左上のボタンでストアに戻る
2. けいさんカード（たす 1〜3 / ひく 1〜2 / 2ばい・3ばい / はんぶん）をタップして並べ、「とべ！」で実行。カエルが数直線（0〜10 / 12 / 16）の上を跳ぶ
3. ゴールの数（金色）に降りたらクリア。跳んだあとに「2 → +3 → 5 → ×2 → 10」のような式が出る
4. わにの数に降りる、線の外に出る（0より小さい・最大より大きい）、奇数を「はんぶん」にする、カードを使い切ってもゴールにいない、と失敗。カードは消えないので直してもう一度
5. わには跳びこえるのは大丈夫。「たす 3 → 2ばい」と「2ばい → たす 3」のように、順番で着地する数が変わることに気づかせるステージがある

### みずのみち

1. ストアで 300 コインで買う。マップでステージを選ぶ
2. じゃぐちから花まで、くだで水の通り道をつくり「ながす！」を押す。押したあとは機械（水）が勝手に流れる
3. ステージ1〜3は置いてあるくだ（青い回転マーク付き）をタップで回すだけ。4からは下のくだ（まっすぐ / まがる / わかれる）を選んで草の上に置く。置いたくだはタップで回り、「けす」を選んでタップすると取れる
4. 置いたときは、となりのくだやじゃぐちにつながる向きに自動でそろう（6歳でも回さずに済むことが多い）
5. ネジ付きの茶色いくだは動かせない。いわの上には置けない
6. くだの口がどこにもつながっていないと「もれちゃった」で水たまりができる。花に届かない枝があると「とどいてないよ」。くだは消えないので直してもう一度
7. ★は何回目の「ながす！」で成功したかで決まる。1回目 ★3、2回目 ★2、それ以降 ★1。動かす前に頭の中で水を流してみる練習
8. ステージが解けることと、最初の状態ではまだ解けていないことは `npm test` のソルバーが確かめる

### まほうのアート

1. 暗い円の上を指でなぞると、光る線が「いくつに ふえる？」で選んだ数（1〜12）だけ回転コピーされ、それぞれ左右にも鏡写しになる。1 なら左右対称（ちょうちょ）
2. 数を変えると、描いた線がその場でもようごと組み変わる。数を選ぶとその数だけ音が鳴る
3. なぞっている間は中心からの距離で音の高さが変わる（ペンタトニックなので何を描いても曲になる）。複数の指で同時に描ける
4. 「くるくる」でもよう全体が回る。回っている上に指を止めておくと、ろくろのように円が描ける
5. 「おまかせ」は押すたびにペンが自動できれいな曲線を描き足す。「もどす」で1本取り消し、ゴミ箱で全部消す
6. いろは にじいろ と5色。レベルや★はない自由遊び。描いたものは人ごとに保存され、次に開くと続きから

## 技術スタック

- Vite 7 / React 19 / TypeScript
- Tailwind CSS v4、motion（アニメーション）、zustand（進捗の localStorage 永続化）
- vite-plugin-pwa（ホーム画面追加・オフライン動作）
- 効果音は Web Audio API で合成（音声ファイルなし）
- タイル・キャラクターはすべてインライン SVG（端末による絵文字の差異を避ける）。まほうのアートだけは描いた線が多くなるので Canvas 2D

## 開発

```bash
npm install
npm run dev        # http://localhost:4649 （同一Wi-Fiのタブレットからは http://<MacのIP>:4649）
npm test           # ゲームエンジンと全ステージの検証（BFS で最短手数 = par を確認）
npm run build      # 型チェック + 本番ビルド → dist/
npm run preview    # dist/ を http://localhost:4650 で配信
```

### ポート番号について

dev が **4649**、preview が **4650**。`vite.config.ts` に固定してある。

Vite はデフォルトが 5173 で、しかも埋まっていると黙って 5174 → 6173 と番号をずらす。
その結果このMacでは複数プロジェクトが 5173 を奪い合い、「localhost:5173 を開いたら別のアプリが出る」
という状態が実際に起きた。そのため独自の番号を決め打ちし、`strictPort: true` で
「埋まっていたらずらさずエラーで止まる」ようにしている。番号を変えるときは `vite.config.ts` の
`DEV_PORT` / `PREVIEW_PORT` を直す。

## 保存しているもの

すべて端末の localStorage。サーバーには何も送らない。

| キー | 中身 |
|---|---|
| `code-kids-session` | ログイン中の人、人ごとのダウンロード済みアプリ、人ごとの買ったアプリと払ったコイン |
| `code-kids-progress` | 音のオン/オフ、人ごと・キャラごとのほしあつめの記録 |
| `code-kids-pittari-jump` | 人ごとのピッタリジャンプの記録 |
| `code-kids-mizu-no-michi` | 人ごとのみずのみちの記録（`bestSlots` には一番少ない「ながす」回数が入る） |
| `code-kids-mahou-art` | 人ごとのまほうのアートの絵（線の座標・数・いろ）。約1万2千点を超えると古い線から捨てる |

`code-kids-progress` はログイン導入前（version 1）はキャラごとの記録だけだった。
version 2 への移行時に、それまでの記録を SEIGEN と AMANE の2人に引き継いでいる（`migrateProgress`）。MIKU と KAYA は空から始まる。

## タブレット対応

- iPad（縦横）と 10インチ / 7インチの Android タブレット（縦横）で表示を確認している
- 余裕のある画面（幅 720px 以上かつ高さ 700px 以上）では `roomy:` バリアントで要素を大きくする（`src/index.css`）
- ストアとログインは本物のタブレット UI に寄せるため、ゲーム用の丸ゴシックではなく端末のフォント（`font-system`）を使う

## アプリ（ゲーム）を追加する

1. `src/apps/catalog.ts` の `APPS` に1件足す。まだ作っていないなら `status: 'soon'` にすると、ストアに「もうすぐ」で並ぶ。`price` を 0 より大きくするとコインで買うアプリになる
2. `src/apps/AppIcon.tsx` にアイコンの SVG を足す
3. 遊べるようになったら `src/apps/<id>/` にアプリの入口（`{ user, onQuit }` を受け取る部品）を作り、`AppRunner.tsx` の `COMPONENTS` に登録して `status: 'ready'` にする

ロジックは UI と分けて `npm test` で検証できるようにする（`src/apps/pittari-jump/engine.ts` が手本）。
ステージ選択・クリア画面・カード列は `src/components` の共通部品を使うと、ゲーム間で操作がそろう。
ステージがあるゲームは、`src/apps/wallet.ts` の `useEarnedCoins` に記録の合計を1行足し、クリア時に `WinDialog` の `coins` へもらったコインを渡す（`src/screens/PlayScreen.tsx` が手本）。

## ステージを追加する

ほしあつめは `src/game/levels.ts`、ピッタリジャンプは `src/apps/pittari-jump/levels.ts` に要素を追加し、`npm test` を実行する。
解けない・`par` が最短と一致しない場合はテストが落ちて正しい値を教えてくれる。
みずのみちは `src/apps/mizu-no-michi/levels.ts` に足す。`par` は無く、テストは「手持ちのくだで解けるか」と「何もしないうちに解けていないか」を調べる。

## デプロイ

https://code-kids-inky.vercel.app/ に Vercel で公開済み。`main` への push で自動デプロイされる。

Vercel の **Root Directory は `code-kids-app`**（このディレクトリ）。リポジトリ直下ではない。
残りは Vite プリセットのままでよく、環境変数も不要。
キャッシュ制御は `vercel.json` に置いてある（Service Worker は毎回再検証させる）。

他のホスティングに移す場合も静的サイトなので `dist/` を配信するだけでよい。
ただし PWA はサブパス配信に対応していないので、ルート配信にすること。
