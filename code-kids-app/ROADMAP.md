## 出し方の方針

- **一気に出さず、1本ずつ出す。** 子どもが今のゲームをクリアしたら次を出す。まとめて出すとありがたみがないため（2026-10-22 ユーザー判断）
- 先に作っておくゲームは `src/apps/catalog.ts` で `status: 'hidden'` にしておく。本番のストアには出ず、`npm run dev` のローカルでだけ見える
- 出すときは `status: 'ready'` に変えて main に push する（Vercel が自動で公開する）。値段はどれも 300 コイン
- 「クリアした」の目安は、今のゲームの全ステージを★1以上で終えたこと

## 作ったけれど、まだ出していないゲーム

2本とも `next-games` ブランチにある。本番には出ていない。`npm run dev` のストアにはふつうに並ぶので、そこで遊んで確かめられる。値段はどちらも 300 コイン。★はどちらも「何回目で成功したか」で決まる（1回目 ★3、2回目 ★2、それ以降 ★1）。

### しわけこうじょう（`src/apps/shiwake-koujou/`）

- シュートから りんご（あか）・つみき（あお）・ほし（きいろ）が順番に出てくる。ベルトコンベアと「わけき」を床に置いて、同じ色の箱へ送る。「うごかす！」を押すと機械が勝手に動く
- 「わけき」は自分の色だけを矢印の向きへ送り、ほかの色はまっすぐ通す。これが条件分岐（もし あかなら みぎ、そうでなければ まっすぐ）
- 失敗は、床に落ちる・ちがう箱に入る・かべで止まる・ぐるぐる回り続ける の4つ。最初の失敗で止まって、その場所に印とやさしい一言が出る。置いた部品は消えない
- 横の欄に「でてくる じゅんばん」が出るので、どの順で来るかを見て組み立てられる
- ステージ: 1〜2 置いてあるベルトを回す / 3〜4 ベルトを置く・かべをよける / 5〜6 わけき1つ / 7 わけき2つで3色 / 8 動かないベルト / 9 かべの多い工場で3色 / 10 ぜんぶまぜ
- 案内役は はこちゃん（段ボール箱のキャラクター）。全ステージが手持ちの部品で解けることをテストのソルバーで確かめている

### おかしわけマシン（`src/apps/okashi-wake/`）

- びんの中のおかしを、どうぶつのおさらに分ける。先に「1さらに なんこ？」「あまりは なんこ？」を数字ボタンで予想してから「くばる！」を押すと、くばるくん（ロボット）が1こずつ順番に配って答え合わせをする
- はずれたら「ほんとうは ○こ だったね。もういちど よそうして みよう！」と本当の答えを見せて、予想をやり直す
- 終わると式が出る。例「7 ÷ 2 = 3 あまり 1」と「3 × 2 + 1 = 7（3こずつ 2さらぶん）」。かけ算は学校の教え方どおり「1つ分 × いくつ分」の順
- ステージ: 1〜6 あまりなし（4÷2 から 15÷5）/ 7〜8 あまりが出る / 9 「3こずつ くばると なんにん？」/ 10 その あまりあり / 11 9こを あまりが出ないように分けられる おさらの数を選ぶ / 12 17÷5
- 数字ボタンは 1〜10、あまりは 0〜5。全ステージの答えがこの範囲に入ることをテストで確かめている

### しきつめガーデン（`src/apps/shikitsume-garden/`）

- 花畑のつちを、はなだん（たて ○ × よこ ○）でぴったりうめる。数字ボタンで形を選び、つちをタップすると そこを左上にして置かれる。はなだんをタップすると消える
- 「うえる！」を押すと、じょうろくんが1行ずつ植えて、花に 1, 2, 3… と番号が出る。行の最後の花は金色になり、3, 6, 9 と増えるのが見える。盤の下で「2 × 3 = 6」が数えながら増える
- 石の上・重なり・はみ出しは止まって×印、すきまが残ると点滅。置いた はなだん は失敗しても残る
- 「なんこ さくかな？」と数を当てるステージもある
- ステージ: 1 1れつ / 2 1×5 を当てる / 3 2れつ / 4 2の だん / 5 3の だん / 6 4の だん（石の道で2つに分ける）/ 7 5の だん を当てる / 8 L字 / 9 4まいの カードから選ぶ / 10 3×4 を回して 4×3 にする（3 × 4 も 4 × 3 も 12）/ 11 2つの合計を当てる / 12 6×5 の畑に石4つ
- 公開前に決めること: 式の順番が「たて × よこ」になっている。おかしわけマシンは学校の教え方の「1つ分 × いくつ分」なので、そろえるなら「1れつの数 × れつの数」に直す（2026-10-23 時点では、ユーザー判断でそのまま）

## 公開するときのチェック

1. `next-games` ブランチを main に取り込み、`catalog.ts` の出したいゲームだけ `status: 'ready'` にする（出さないほうは `hidden` のまま）
2. `npm test` と `npm run build` が通ることを確かめる
3. README のゲーム一覧の「状態」を直し、この表の「状態」も「公開中（日付）」にする
4. main に push する
